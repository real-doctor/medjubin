# 의주빈 아카이브 (Public Doctor Malpractice & Crime Media Archive)

> **대한민국 양의사 범죄 및 중대 의료과실 공공보도 아카이브 & AI 인제스천 스튜디오**  
> 공익 목적의 대한민국 의료인(양의사) 범죄·의료사고 언론 보도 데이터베이스 및 지능형 3분할 팩트체크 시스템입니다.

---

## 🌟 주요 기능 및 특징

### 1. 메인 아카이브 (`index.html`)
* **SVG 인터랙티브 전국 지도**: 17개 시·도별 사건 발생 통계 시각화 및 원클릭 지역 필터링
* **다차원 정밀 필터링**: 범죄 유형(성범죄, 마약류, 대리수술, 의료사고, 리베이트 등), 발생 연도(2020~2024), 지역별 실시간 검색
* **Chart.js 통계 대시보드**: 유형별 도넛 차트 및 연도별 추이 분석
* **심층 사건 타임라인 모달**: 언론 보도 출처, 수사/처벌 진행 단계, 면허 행정처분 상황 제공
* **반응형 다크/라이트 테마**: 프리미엄 UI/UX 및 모바일 최적화

### 2. 관리자 AI 스튜디오 (`admin.html`)
* **1차 3분할(승인/검토/배제) 스마트 로컬 고속 트리거 (0.1초)**:
  - **✅ 직통 승인 (PASS)**: 구속, 실형, 대리수술, 강간, 의사 피의자 검거 명시 사건
  - **⚠️ AI 정밀 검토 (REVIEW)**: 무죄/무혐의 언급, 성폭행/성추행/몰카 등 쟁점 기사
  - **❌ 즉시 배제 (REJECT)**: 한의사/치과의사, 해외 사례(中·日·美·印 등), 복지부 정책기사, 의향(意思) 동음이의어('거부 의사' 등)
* **2차 Gemini 3.7+ AI 병렬 팩트체크**:
  - Google Gemini 3.7 Flash / 3.5 Flash Lite 동시 병렬(5~10개) 팩트체크 지원
  - 실시간 API 키 연결 테스트 및 커스텀 프롬프트 편집기 제공
* **원클릭 아카이브 발행 (Publish)**:
  - 검증 완료된 사건을 아카이브에 즉각 반영하고 `data.js` 파일 자동 생성/다운로드

## 📂 프로젝트 구조

```text
jubin/
├── index.html              # 메인 아카이브 웹 애플리케이션
├── admin.html              # 관리자 AI 스튜디오 & 3분할 파이프라인
├── css/
│   ├── index.css           # 글로벌 디자인 토큰 및 기본 스타일
│   ├── components.css      # 카드, 지도, 모달, 차트 등 컴포넌트 스타일
│   └── admin.css           # 관리자 스튜디오 전용 스타일
├── js/
│   ├── data.js             # 아카이브 정식 검증 데이터베이스
│   ├── app.js              # 메인 앱 상태 관리 및 이벤트 바인딩
│   ├── map.js              # SVG 지도 인터랙션 및 지역 통계
│   ├── charts.js           # Chart.js 시각화 대시보드
│   ├── filter.js           # 다중 조건 검색 및 필터링 엔진
│   ├── modal.js            # 상세 타임라인 모달 렌더러
│   ├── admin.js            # 3분할 필터 & Gemini AI 병렬 팩트체크 엔진
│   └── admin_queue.js      # 수집된 원본 기사 대기열
└── scripts/
    ├── heavy_collector.js  # 대량 뉴스 크롤러 (Google News RSS 등)
    └── validate_and_build.js # 데이터 검증 및 빌드 스크립트
```

## 🚀 로컬 실행 방법

별도의 복잡한 빌드 과정 없이 정적 웹 서버로 즉시 구동 가능합니다:

```bash
# http-server 실행
npx -y http-server . -p 8080 -c-1
```

브라우저에서 접속:
* 메인 아카이브: `http://localhost:8080`
* 관리자 AI 스튜디오: `http://localhost:8080/admin.html`
